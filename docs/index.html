StudioLive MIDI Controller

MIDI control surface for PreSonus StudioLive III mixers — map DAW faders, mute, and solo to your mixer over the network.

▶ Live Demo ⚡ Quick Start GitHub Releases

Overview

StudioLive MIDI Controller bridges your DAW and your PreSonus StudioLive III mixer. Move a fader in Logic Pro (or any DAW with MIDI output) and the physical mixer fader moves in real time — and vice versa. You can also trigger mute/solo from pads or buttons on any MIDI controller.

It is not a replacement for Universal Control — it works alongside it, adding DAW-driven automation and remote control that Universal Control doesn't provide.

FeatureDescription
MIDI ↔ MixerCC, Note, and Note-Value modes with real-time feedback
All channel typesLINE, AUX, FX, SUB, DCA, MAIN, and Mute Groups

Installation

From DMG (recommended)

  1. Download the latest .dmg from Releases.
  2. Open the DMG and drag StudioLive MIDI Controller to Applications.
  3. Launch from Launchpad or Applications.

From Source

git clone https://github.com/featherbear/presonus-studiolive-api.git
git clone https://github.com/sandinak/studiolive-midi-controller.git
cd studiolive-midi-controller
npm install && npm run build && npm start
NoteThe presonus-studiolive-api repo must be cloned alongside this repo in the same parent directory — it is referenced as a local dependency.

First Launch

1 — Connect to your mixer

  1. Click the Mixer status dot in the header.
  2. Click Discover Mixers. Found mixers appear as they are detected.
  3. Click Connect next to your mixer. The IP is saved for automatic reconnection on future launches.

2 — Connect a MIDI device

  1. Click the MIDI status dot in the header.
  2. Select your device (e.g. Logic Pro Virtual Out) and click Connect.
  3. Optionally assign a colour to the device — all mappings from it are highlighted with that colour.

3 — Create your first mapping

  1. Double-click any channel fader, or right-click → Edit Volume.
  2. Set MIDI Type, Channel, and the CC/Note number.
  3. Click Save. The fader border glows with the device colour.

4 — Save your profile

Click Save in the toolbar. Your mixer IP, MIDI device, and all mappings are stored as a JSON preset file.

  • 2Toolbar — Add Channel, the view filter, and the mute-group buttons (a lit ring means that group is muting its members).
  • 3Channel strip area — horizontal row of faders, right-justified. Channels fill from the right; scrolls left when there are more channels than fit.
  • 4Status bar — the latest status message, the loaded profile and when it was last saved, and the app version (click to open this changelog).

  • 2Input source icon — shows the physical input type: XLR/Analog, Network, USB, or SD Card.
  • 3M button — toggle mute. Right-click to edit or learn a MIDI mapping for mute.
  • 4S button — toggle solo. Glows yellow when active. Right-click to map.
  • 5Fader — drag to adjust level. The orange line shows the current MIDI-received position. Right-click → Edit/Learn volume mapping.
  • 6Channel icon & number — emoji icon from mixer config. The small dot to the left of the number is the level indicator.

  • 8MIDI mapping badge — shows the CC/Note assigned to this channel. Border colour matches the MIDI device colour.

Creating Mappings

A mapping links one MIDI message (CC, Note, or Note-Value) to one mixer action (volume, mute, or solo) on one channel.

Add or edit a volume mapping

  1. Double-click the fader, or right-click it → ✏️ Edit Volume.
  2. In the mapping dialog, set MIDI Type, MIDI Channel, and the CC or Note number.
  3. Optionally click 🎹 Listen — move a fader/knob on your controller and the CC number fills in automatically.
  4. Click Save.

Add or edit a mute / solo mapping

  1. Right-click the M button → ✏️ Edit Mute Mapping.
  2. Set MIDI Type to Note and the note number that your controller sends.
  3. Click Save. The M button border now glows with the device colour when mapped.

The same flow applies to solo (S button).

MIDI Learn

Use right-click → 🎹 Learn Volume / Mute / Solo on any channel to open the mapping dialog and immediately start listening. Move the intended knob or pad on your controller and it maps automatically.

Clear a mapping

Right-click the channel strip → 🧹 Clear All MIDI Mappings to remove volume, mute, and solo mappings for that channel in one step.

Channel Settings Menu

Click a channel's instrument icon to open its settings. Everything here is read live from the mixer and written straight back to it.

  • 1Input — 48V phantom power, polarity invert, and sum to mono.
  • 2Processing — gate, compressor, EQ and limiter in/out.
  • 3Preamp — gain in decibels, using the range the console publishes for itself (0–60 dB on a StudioLive III). Written on release, not on every drag.
  • 4Console Presets — the mixer's own preset library, with the ones matching this channel's instrument listed first and shown in green.

A switch the mixer has not reported shows as unavailable rather than as off, so an unknown state is never mistaken for a known one. Recalling a preset replaces the entire channel strip — gain, EQ, compressor, gate and limiter — so it always confirms first and cannot be undone from the app.

Locked in Run mode

Phantom power can damage ribbon microphones, and an accidental polarity flip on a summed source is a silent, hard-to-trace way to gut the low end mid-set. Gain is a setup control — you ride the fader, not the preamp — and it is the one change here that can cause feedback. The processor switches stay available, because dropping a gate or bypassing a compressor during a performance is normal and instantly reversible.

Enabling 48V asks for confirmation even in Edit mode; turning it off never does, since that is the safe direction. The lock is enforced in the main process rather than only by greying out the control, so a stale window, a stray IPC message, or a MIDI controller sending the wrong note cannot flip phantom power during a show.

Edit & Run Mode

The app separates configuration from performance. Toggle between the two with the EDIT / RUN button at the far right of the header.

Transport Control

The ▶ Play / ⏸ Stop button, visible in Run mode, sends MIDI Start and Stop messages to every connected MIDI output. Logic Pro, Ableton Live and other DAWs that follow MIDI transport respond to it.

Mute Groups

Mute groups are defined on the mixer itself (in Universal Control). The app reads them and shows a button for each active group in the toolbar.

  • Click a mute-group button to toggle muting of all assigned channels simultaneously.
  • Right-click a mute-group button to map it to a MIDI pad or note.
  • The button glows when the group is active (at least one channel muted by the group).

Touch Control (TUIO)

The app listens for TUIO multi-touch messages, so a tablet or touch surface can move several faders at once — something a mouse cannot do.

Setting it up

  1. Install a TUIO-capable app on the tablet. TouchOSC and Lemur both work, as does anything with TUIO output.
  2. Point it at your computer's IP address on UDP port 3333.
  3. Start sending. Nothing needs configuring in this app — the listener runs from startup.

How touches map to faders

The touch surface is treated as the fader strip itself:

  • Horizontal position selects the fader — the surface is divided evenly across every fader currently visible, so the filter setting changes what your touches reach.
  • Vertical position sets the level — top is full, bottom is silence.
  • Each finger keeps the fader it first landed on, so sliding sideways won't jump to a neighbour mid-move.
NotePort 3333 is a common TUIO default. If another app already holds it, this app logs a warning at startup and runs without touch support — quit the other app and restart.

Profiles

A profile stores your entire configuration as a JSON file:

  • Mixer identity — IP, model, device name and serial number (used for auto-reconnect and mixer matching)
  • MIDI device names and their colour assignments
  • DCA group colours
  • All volume, mute, solo, and mute-group mappings
  • Display preferences — fader smoothing, level display, peak hold, fader stacking, filter state
  • Whether MIDI feedback to the DAW is enabled

Profiles are saved to:

macOS:   ~/Library/Application Support/StudioLive Midi Controller/
Windows: %APPDATA%\StudioLive MIDI Controller\

A profile named default.json is loaded automatically at startup.

Working with more than one mixer

A profile remembers which mixer it was built for — by serial number where the mixer reports one, otherwise by model and IP address. Connect to a mixer that doesn't match and the app says so, offering to start a fresh profile for it.

Creating one clears the mappings and DCA colours, which belong to the mixer, while keeping your MIDI devices, device colours and display preferences, which belong to your setup. The previous profile file is left untouched on disk, so you can load it again when you reconnect to the original mixer.

NoteThis matters because channel layouts differ between models — a 32-channel profile applied to a 16-channel mixer would map faders onto channels that don't exist.

Logic Pro Setup

Logic Pro exposes a built-in virtual MIDI port called Logic Pro Virtual Out that is visible to all CoreMIDI apps on the same Mac — no extra setup required.

Step 1 — Configure Logic tracks

  1. For each mixer channel, create an External MIDI track in Logic.
  2. In the track Inspector, set MIDI Out to Logic Pro Virtual Out and pick a unique MIDI Channel (1–16) per mixer channel.
  3. Draw CC 7 (Volume) automation on the track, or record fader moves during playback.

Step 2 — Connect the app

  1. Click the MIDI status dot in the app header to open the MIDI panel.
  2. Select Logic Pro Virtual Out from the device list and click Connect.

Step 3 — Add mappings

  1. Right-click a fader → Learn MIDI mapping, then press Play in Logic and move the corresponding fader to auto-detect CC and channel.
  2. Alternatively, right-click → Edit Mapping and enter the CC number and MIDI channel manually.
  3. The MIDI channel in the mapping must match the channel set on the Logic track.

For the advanced MIDI Environment approach (a visual fader panel inside Logic) see the Logic Quick Reference.

ImportantMIDI channel numbers in Logic must match the channels in the app's mappings. Mismatched channels are the most common reason faders don't respond.

DCA Colors

Each of the 8 DCA groups can be given a colour of its own — right-click a DCA fader's label to choose one. LINE channels belonging to that DCA carry a small badge in the same colour, which makes group membership readable at a glance.

DCA colours are stored per profile rather than globally, since they describe one particular mixer's group layout.

MIDI Device Colors

  1. Open the MIDI connection panel (click the MIDI status dot).
  2. Click the color swatch next to a connected device name.
  3. Choose a color. Mapped faders immediately show a small colored dot badge.

Colors are stored in the preset so they persist across launches.

Troubleshooting

Mixer not found during discovery

  • Ensure the mixer and your Mac are on the same subnet.
  • Check the firewall — allow TCP port 53000 (mixer control) and UDP port 47809 (discovery broadcasts).
  • Try entering the IP manually in the Mixer connection panel — a typed-in address is probed directly and doesn't depend on discovery working.
NoteIf PreSonus Universal Control is running it holds UDP port 47809, so the app can't receive discovery broadcasts. To work around this the app also TCP-probes every address on your local subnets, and your mixer should still appear — it may just take a few seconds longer. Subnets wider than /22 are skipped to keep the sweep bounded.

MIDI not working

  • Check the MIDI status dot in the header — it must be green.
  • Open the MIDI Log and verify messages arrive when you move a knob.
  • Confirm MIDI channels match between the DAW track and the mapping.

Faders not responding (DAW → Mixer)

  • Both mixer and MIDI dots must be green.
  • Verify the mapping uses the correct CC and MIDI channel.
  • In Logic, confirm the track's MIDI Out is set to Logic Pro Virtual Out (track Inspector).

Jerky fader movement

  • Increase Fader Smoothing in Preferences (try 400–500 ms).
  • Use a wired network connection rather than Wi-Fi.

Level dots always grey

  • The mixer meter stream requires an active connection — check the mixer status dot.
  • Play audio through the mixer and confirm signal is present on the physical meters.

Profile not loading

  • Check the preset directory: ~/Library/Application Support/StudioLive Midi Controller/
  • Verify the JSON is valid (open in a text editor).

Fader border pulsing red/white

  • A pulsing dashed red/white border means the MIDI device assigned to that fader is not currently connected.
  • Reconnect the MIDI device, or open Preferences → MIDI Device Colors and remove the color assignment to clear the animation.

Level meter not working

  • Open Preferences and confirm Level Display is set to Indicator or Meter (not None).
  • Level data requires an active mixer connection — check the status bar dot is green.
  • Play audio through the mixer and verify signal on the physical meters; the app only shows levels when the mixer is streaming meter data.
